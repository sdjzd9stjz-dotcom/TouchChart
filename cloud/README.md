# TouchChart 互联网中继部署

此包是给 Windows 原生电脑 + 手机浏览器使用的独立中继服务。每台电脑创建自己的私密房间；一个房间只能绑定一台手机浏览器。不同电脑可同时使用，同一公网 IP 下的设备也可分别配对。它不提供网页电脑制谱台；录制、音乐和完整 PEZ 导出在原生软件中完成。

## Linux 服务器部署

需要自己的域名、服务器和 Docker Compose。将域名的 DNS 指向服务器，开放 TCP 80/443。解压本包到独立目录，新建 `.env`，填写 `DOMAIN=你的域名`（不加 https://）。在该目录运行：

```
docker compose up -d --build
docker compose logs --tail=50
```

Caddy 提供 HTTPS，后端 8791 不映射到公网。访问 `https://你的域名/health` 应返回 `{"ok":true}`。然后电脑软件填写 `https://你的域名` 并点「创建配对」，复制专属手机链接到手机浏览器。无需电脑与手机同一 Wi-Fi。

不要将旧版 touchchart.py 的局域网服务直接公开；本包入口为 cloud_server.py。旧 APK 没有公网配对协议，请使用手机浏览器。

## 本地验证

Python 3.10+，无需 pip 依赖：

```
python cloud_server.py --host 127.0.0.1 --port 8791
```

原生软件填 `http://127.0.0.1:8791` 可以本机验证。公网连接强制 HTTPS。本包的 Docker/Caddy 文件已提供，当前交付未在实际 Linux 服务器执行容器构建或公网发布。

## 隔离与运行边界

配对邀请和电脑/手机令牌均为独立随机值；手机不能读取谱面、停止服务或操作其他房间。服务按浏览器保存的凭据识别设备，换浏览器或清空存储视为另一设备。手机链接只应交给对应手机；持有未使用邀请的人可成为首个绑定设备。

默认最多 100 个房间，128 个同时处理的连接，每房间触控队列最多 5000 个事件。达到容量时明确拒绝，不无限积压。实际可承载数量与服务器及网络相关，未做 100 房间负载验收。互联网会增加延迟；超过两秒的积压输入在电脑丢弃。按住手指离线会自动释放。

房间无活动一小时过期。服务重启或升级会清空配对，电脑重新创建配对即可；本地音符不在服务器，不受其重启影响。请在关闭电脑程序前导出谱面。关闭配对会撤销旧手机令牌。

源文件和测试日志随包提供。测试覆盖本机真实 HTTP 多房间/重复批次/权限隔离，以及真实 Edge 手机模拟触控；这些不代表公网或实体手机已经验收。
